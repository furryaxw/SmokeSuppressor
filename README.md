# SmokeSuppressor

[中文](README.zh.md) | **English**

A mod for Sprocket `0.2.55.5` (BepInEx 6 IL2CPP) that hides the smoke layers which
accumulate over time, while keeping one-shot effects intact (muzzle flash, sparks,
shockwave, distortion, impact dust, vehicle fires, and so on).

## Hidden layers

| Toggle | Output layers hidden |
| --- | --- |
| Hide engine accumulation | `ExhaustSmoke/System (5)` |
| Hide muzzle accumulation | `MediumCannonFire/System (10)` |
| Hide ground impact smoke | `ShellImpact_dirt/System (1)` and `System (4)` |
| Hide armour impact smoke | `ShellNonPenetration/System` and `ShellPenetration/System (5)` |

All four toggles are enabled by default (hidden by default). They are provided by the
SprocketModAPI config service and can be switched individually on the
**Smoke Suppressor** page of the in-game Mod menu.

## How it works

- The output layers are identified by a static inventory of the VFX assets in the game's
  resources: every accumulation layer is an output with `task=4`, `taskType=1073741830`
  that uses `WispySmoke03_8x8`; the remaining outputs in the same asset are one-shot
  layers and must be kept.
- Suppression works by disabling the shader pass of the material generated by that output
  after `VisualEffect.Play()` (via `Material.SetShaderPassEnabled`). When the output
  material has not been generated yet, the mod retries for a limited number of frames for
  that instance only.
- No game resource files are modified.

## Requirements

- Sprocket `0.2.55.5`, BepInEx `6.0.0-be.788` (IL2CPP / net6)
- Requires [SprocketModAPI](https://github.com/furryaxw/SprocketModAPI): config page and in-game menu
- Windows x64

After a game update, the `System (N)` indices in the VFX assets may change, so the
resources have to be re-inventoried and the rules updated.

## Installation

1. Install BepInEx 6 (IL2CPP) for Sprocket.
2. Place `SprocketModAPI.dll` and `SmokeSuppressor.dll` into `BepInEx\plugins`.
3. Launch the game.

## Troubleshooting

`Calibration.Enabled` in `BepInEx\config\furryaxw.smoke-suppressor.cfg` (default `false`)
enables the output-layer calibration probe: **F6** toggles it, **F7** advances to the next
candidate, and **F8** confirms. While it is active it disables the other outputs and shows
only the current candidate, which lets you identify which layer a given `System (N)`
actually is.

## Building

```powershell
dotnet build .\SmokeSuppressor\SmokeSuppressor.csproj -c Release
```

- Deploys to `$(SprocketGameRoot)\BepInEx\plugins` by default
- `-p:SkipModDeploy=true` builds without deploying
- `-p:SprocketGameRoot="D:\Games\Sprocket"` points at a different game directory
